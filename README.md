# 📋 Kanban Task Board

A modern Kanban board built using HTML, CSS, and JavaScript.

## 🚀 Features
- Add tasks
- Drag and Drop between columns
- Low / Medium / High priority
- Dark Mode
- Clean UI

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript (Drag & Drop API)
